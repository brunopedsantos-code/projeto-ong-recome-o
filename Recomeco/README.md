Recomeço — Projeto ONG

📌 Sobre o projeto

O Recomeço é um projeto acadêmico de desenvolvimento web que representa uma plataforma para uma organização não governamental (ONG).

A proposta é apresentar a organização, divulgar seus projetos e facilitar o engajamento de pessoas interessadas em contribuir com suas iniciativas.

🎯 Objetivos

Aplicar os fundamentos de HTML5.

Organizar páginas web com estrutura semântica.

Utilizar CSS para estilização e identidade visual.

Desenvolver uma navegação clara e intuitiva.

Criar uma base para futuras melhorias com JavaScript.

📄 Páginas do projeto

Início (index.html): página principal.

Quem Somos (quem-somos.html): apresentação da organização.

Projetos (projetos.html): divulgação das iniciativas.

Cadastro (cadastro.html): página destinada ao cadastro de interessados.

🛠️ Tecnologias

HTML5

CSS3
